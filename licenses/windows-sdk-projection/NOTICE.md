# Windows SDK projection for .NET

DriverCompass ships `Microsoft.Windows.SDK.NET.dll` and `WinRT.Runtime.dll` from the package `Microsoft.Windows.SDK.NET.Ref` (added automatically by the .NET SDK for `net10.0-windows10.0.22621.0`). The package contains no license file; its license terms are the Windows SDK license terms:

https://aka.ms/WinSDKLicenseURL

`WinRT.Runtime.dll` is part of C#/WinRT, which is published under the MIT license:

https://github.com/microsoft/CsWinRT/blob/master/LICENSE
